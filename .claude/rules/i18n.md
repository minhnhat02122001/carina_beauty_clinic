# i18n Conventions

- Every route lives under `src/app/[locale]/`; supported locales are
  declared in `src/i18n/routing.ts` (currently `en`, `vi`).
- No user-facing string may be hardcoded in a component. Add the key to
  **both** `src/messages/en.json` and `src/messages/vi.json`, then read it
  with `useTranslations`/`getTranslations` from `next-intl`.
- Use `Link`, `useRouter`, `usePathname` from `@/i18n/navigation` (not
  `next/link` or `next/navigation`) so routes stay locale-aware.
- A message key added to one locale file without the other is a bug, not a
  TODO — translate it before committing, or ask the user for the Vietnamese
  copy if unsure.
